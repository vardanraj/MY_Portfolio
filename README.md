# Developer Portfolio[cite: 1]

A premium React developer portfolio featuring responsive fluid typography, Figma-inspired neon gradients, and elegant route transitions.[cite: 1]

## 🚀 Features
*   **Dynamic Theme Switching:** Light and dark mode support with page-specific gradient accents.[cite: 2]
*   **Fluid Typography & Layouts:** Responsive design that looks great on all devices.[cite: 2]
*   **Interactive Media Gallery:** Advanced lightbox with filtering for projects and certificates.[cite: 2]
*   **Framer Motion Animations:** Elegant route transitions and scroll-linked progress indicators.[cite: 2]
*   **Figma-Inspired UI:** Glassmorphism effects, neon gradients, and premium layout grids.[cite: 2]
*   **Gemini API Integration:** Prepared for server-side AI capabilities.[cite: 1, 2]

## 💻 Tech Stack
*   **Frontend:** React 19, React Router 7, TypeScript, Tailwind CSS v4, Motion (Framer), Lucide Icons[cite: 1, 2]
*   **Build & Tools:** Vite 6, ESBuild, Express, Dotenv, Google GenAI SDK[cite: 1, 2]

## 🛠️ Installation & Setup
1.  **Clone the repository** and navigate into the directory.[cite: 2]
2.  **Install dependencies:**[cite: 2]
    ```bash
    npm install
    ```
3.  **Environment Setup:** Create a `.env` file based on `.env.example`:[cite: 1, 2]
    ```env
    GEMINI_API_KEY="your_api_key_here"
    APP_URL="http://localhost:3000"
    ```
4.  **Start the development server:**[cite: 2]
    ```bash
    npm run dev
    ```
    The app will be available at `http://localhost:3000`.[cite: 2]

## 📂 Project Structure
*   `src/App.tsx`: Main application component with routing and theme logic.[cite: 2]
*   `src/components/`: Reusable UI components (Navbar, Hero, Gallery, etc.).[cite: 2]
*   `src/pages/`: Route components (Home, About, Projects, etc.).[cite: 2]
*   `src/data/portfolioData.ts`: Centralized content for projects, skills, and personal info.[cite: 2]
*   `src/images/`: Static assets and certificates.[cite: 2]

## 📜 Available Scripts
*   `npm run dev`: Starts the Vite development server.[cite: 1, 2]
